# OneBox

OneBox 是一个无构建依赖的静态 PWA，把计算器、中文日历、天气、单位换算和单词本放在一个可离线使用的工具箱里。

## 能力闭环

- 计算器：括号、百分比、键盘操作、安全表达式解析、最近计算历史。
- 日历：月视图、农历、干支生肖、二十四节气、中国法定节假日、补班、个人日程，以及日程的本地增删。
- 天气：城市搜索、当前位置、实时天气、五日预报、网络失败时的最近结果缓存。
- 转换：长度、重量、面积、体积、速度、时间、数据、温度，支持交换单位和复制结果。
- 单词：增删改、搜索、分页（每页 5 条）、待复习/已掌握、抽认卡复习、JSON 导入导出。

所有个人数据（主题、计算历史、日程、单词、最近天气）都保存在当前设备的 `localStorage`。天气使用 Open-Meteo；节假日在线更新使用开源的 `NateScarlet/holiday-cn`，并内置 2026 年离线兜底数据；农历使用浏览器内置的 `Intl` 中文历法实现，节气使用 1900–2099 年的标准近似算法。

## 本地运行

```bash
python3 -m http.server 4173 -d dist
```

然后打开 <http://localhost:4173>。PWA 的 Service Worker、安装按钮和离线缓存都需要 HTTP(S) 上下文，不能直接双击 `index.html`。

## 发布前检查

1. 通过静态服务器打开首页，确认 manifest 和 Service Worker 注册成功。
2. 依次走完五个工具的新增/编辑/删除/刷新闭环；天气需验证城市搜索和无网缓存态。
3. 在浏览器 Application/Storage 面板确认本地数据只写入 `onebox.*` 键。
4. 用 Lighthouse 或浏览器 PWA 检查器确认可安装、离线应用壳可启动、无控制台错误。

仓库不需要 npm install 或构建步骤，发布 `dist/` 目录即可。
